# Student Audio Library

A free, simple QR-code audio library for students.

## Add your audio
Create an `audio` folder and put your MP3 files inside it:
- welcome.mp3
- lesson01.mp3
- lesson02.mp3

Edit `index.html` to change titles/descriptions or add more audio cards.

## Free hosting
Upload these files to a GitHub repository and enable GitHub Pages.

Then generate a QR code pointing to your GitHub Pages address.

Example:
https://YOUR-USERNAME.github.io/student-audio-library/
